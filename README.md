# CineHub

Movie discovery app — React (Vite) frontend + Express backend. Browse TMDB movies,
keep a watchlist, and rate movies with community averages. MongoDB stores users,
sessions, watchlists, and ratings.

## Structure

```text
cinehub/
├── frontend/        # React + Vite + React Router + Tailwind → deploy on Vercel
│   ├── src/pages/   # Home, MovieDetail, Trending, Genres, Search, Watchlist, Profile, Login, Register
│   ├── src/components/
│   ├── vercel.json  # SPA fallback rewrite
│   └── .env.example
├── backend/         # Express API (plain JavaScript) → deploy on Render
│   ├── src/routes/  # auth, movies, watchlist, profile
│   ├── src/middleware/  # cookie-session auth, error handler
│   └── .env.example
├── render.yaml      # Render Blueprint (optional — you can also configure manually)
└── LICENSE
```

## Local development

Requires Node 20+.

```bash
# backend (http://localhost:5000)
cd backend
npm install
cp .env.example .env   # fill in real values, never commit this file
npm run dev

# frontend (http://localhost:5173, /api proxied to :5000)
cd frontend
npm install
npm run dev
```

## Environment variables (set real values in dashboards, not in git)

Backend (`backend/.env` locally / Render Environment tab):

| Key | Example |
| --- | --- |
| `PORT` | `5000` |
| `CLIENT_URL` | `http://localhost:5173` locally, Vercel URL in production |
| `MONGODB_URI` | `mongodb+srv://user:pass@cluster/cinehub?retryWrites=true&w=majority` |
| `TMDB_API_KEY` | TMDB API key or read-access bearer token (server-side only) |
| `JWT_SECRET` | long random string that signs login tokens (auto-generated by `render.yaml`) |
| `NODE_ENV` | `development` locally, `production` on Render |

Frontend (`frontend/.env` locally / Vercel Environment Variables):

| Key | Example |
| --- | --- |
| `VITE_API_URL` | empty locally (Vite proxy), `https://cinehub-api.onrender.com` in production |

## Deploy

**Frontend → Vercel:** import the repo, set Root Directory to `frontend`,
build command `npm run build`, output directory `dist`,
add `VITE_API_URL` pointing at the Render backend URL.

**Backend → Render:** either use the Blueprint (`render.yaml` at repo root —
health check `/health`, install `npm install`, start `npm start`) or create a
Web Service manually with Root Directory `backend` and the same commands.
Add `CLIENT_URL` (Vercel URL), `MONGODB_URI`, `TMDB_API_KEY`, `NODE_ENV=production`.

Auth is simple token login — no cookies. Register/login return `{ token, user }`,
the app stores the token in `localStorage` and sends it as
`Authorization: Bearer <token>`. Logout just deletes the stored token.

## API overview

- `POST /api/auth/register|login|logout`, `GET /api/auth/me`
- `GET /api/movies/home|trending|category/:name|search|genres|genres/:id|:id`
- `PUT /api/movies/:id/rating` (auth)
- `GET|POST|DELETE /api/watchlist` (auth)
- `GET /api/profile` (auth), `GET /health`
